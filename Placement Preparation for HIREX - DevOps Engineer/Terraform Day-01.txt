                    🛠️ Introduction to Terraform
====================================================================

🔰 WHAT IS TERRAFORM?
--------------------------------------------------------------------
Terraform is an **open-source Infrastructure as Code (IaC)** tool
developed by **HashiCorp**.

It allows you to define, provision, and manage cloud infrastructure 
using **declarative configuration files**.

🌐 Supported Providers:
- AWS, Azure, GCP, OCI, Kubernetes, GitHub, Docker, and more

--------------------------------------------------------------------
📘 WHY USE TERRAFORM?
--------------------------------------------------------------------
✅ Automate infrastructure setup  
✅ Version control your infrastructure like code  
✅ Repeatable & consistent deployments  
✅ Easy to scale, rollback, and track changes  
✅ Supports multi-cloud deployments

--------------------------------------------------------------------
🧠 CORE CONCEPTS
--------------------------------------------------------------------

🔹 **Providers**
   - Define the cloud/platform to work with
   - Example: `aws`, `azurerm`, `google`, `kubernetes`

🔹 **Resources**
   - Basic building blocks (e.g., EC2 instance, S3 bucket)

🔹 **Variables**
   - Allow customization and reusability

🔹 **State File**
   - `.tfstate` tracks current infrastructure state
   - Important for sync between code and reality

🔹 **Modules**
   - Group and reuse configurations

🔹 **Data Sources**
   - Fetch info from external or existing infrastructure

--------------------------------------------------------------------
📁 BASIC TERRAFORM FILE STRUCTURE
--------------------------------------------------------------------
Typical files:
```

main.tf         → Primary config
variables.tf    → Input variables
outputs.tf      → Output values after apply
terraform.tfvars → Actual variable values

````

--------------------------------------------------------------------
📜 SAMPLE TERRAFORM CODE (AWS EC2)
--------------------------------------------------------------------
```hcl
provider "aws" {
  region = "us-east-1"
}

resource "aws_instance" "my_vm" {
  ami           = "ami-0c55b159cbfafe1f0"
  instance_type = "t2.micro"

  tags = {
    Name = "TerraformDemo"
  }
}
````

➡️ This creates a t2.micro EC2 instance in AWS using Terraform.

## 🚦 BASIC TERRAFORM COMMANDS

🔹 Initialize project:

```
terraform init
```

🔹 Validate code syntax:

```
terraform validate
```

🔹 See what will be created/changed:

```
terraform plan
```

🔹 Apply changes to infrastructure:

```
terraform apply
```

🔹 Destroy all resources:

```
terraform destroy
```

🔹 Format code properly:

```
terraform fmt
```

---

## 🔐 TERRAFORM STATE (.tfstate)

* Terraform stores all applied changes in a **state file**
* Important to **backup** or use **remote backends** (like S3)

Avoid editing `terraform.tfstate` manually!

---

## 🌐 REMOTE BACKENDS (Advanced)

* Store state securely in cloud (e.g., AWS S3, Azure Storage)
* Enable team collaboration and locking
