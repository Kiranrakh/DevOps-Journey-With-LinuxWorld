========================================
🌟 Introduction to Grafana
========================================
Grafana is an open-source analytics and interactive visualization web application. It allows you to query, visualize, alert on, and understand your metrics from various data sources like Prometheus, InfluxDB, Graphite, Elasticsearch, and many more.

🔹 Features:
- Customizable dashboards
- Support for multiple data sources
- Alerting and notifications
- Plugins for enhanced functionality

========================================
⚙️ Installing Grafana on Amazon Linux 2 (YUM Method)
========================================
1️⃣ Launch an EC2 instance using Amazon Linux 2 AMI.  
2️⃣ Open all ports temporarily for public access (for demo/test only).  
3️⃣ Connect via SSH:
```

ssh -i your-key.pem ec2-user@\<EC2\_PUBLIC\_IP>

```

4️⃣ Run the following commands to install Grafana via YUM:
```

sudo yum update -y

sudo tee /etc/yum.repos.d/grafana.repo<\<EOF
\[grafana]
name=Grafana OSS
baseurl=[https://packages.grafana.com/oss/rpm](https://packages.grafana.com/oss/rpm)
repo\_gpgcheck=1
enabled=1
gpgcheck=1
gpgkey=[https://packages.grafana.com/gpg.key](https://packages.grafana.com/gpg.key)
sslverify=1
sslcacert=/etc/pki/tls/certs/ca-bundle.crt
EOF

sudo yum install grafana -y
sudo systemctl daemon-reexec
sudo systemctl enable grafana-server
sudo systemctl start grafana-server

```

5️⃣ Access Grafana UI in browser:  
```

http\://\<EC2\_PUBLIC\_IP>:3000

```
Default login credentials: `admin / admin`

========================================
📦 Installing Grafana via Standalone Binary (Manual Method)
========================================
1. Visit: https://grafana.com/grafana/download  
2. Choose: **Linux → 64-bit → Standalone Linux Binaries**
3. Download and install via commands:
```

wget [https://dl.grafana.com/oss/release/grafana-11.0.0.linux-amd64.tar.gz](https://dl.grafana.com/oss/release/grafana-11.0.0.linux-amd64.tar.gz)
tar -zxvf grafana-11.0.0.linux-amd64.tar.gz
cd grafana-11.0.0/bin/
./grafana-server &
jobs

```

📡 ADD AWS CLOUDWATCH AS A DATA SOURCE
==================================================================

✅ Step-by-step CloudWatch Integration:

➡️ In AWS Console:
1. Go to EC2 → Select Instance → Enable detailed monitoring

➡️ In Grafana:
1. Go to ⚙️ Settings → Data Sources → Add Data Source
2. Select CloudWatch and fill:
   - Name: AWS CloudWatch
   - Auth: Access Key + Secret Key
   - Region: ap-south-1
3. Click Save & Test

➡️ In Explore:
- Choose EC2 as service
- Use Query Builder
- Namespace: AWS/EC2
- Metric: CPUUtilization
- Aggregation: Average
- Filter: InstanceId = <your-instance-id>
- Run Query

==================================================================
📊 CREATING A MONITORING DASHBOARD
==================================================================

📌 Steps:
- ➕ → Dashboard → Add Panel
- Add CloudWatch metric query
- Set visualization type (Graph, Gauge, etc.)
- Click Apply → Save Dashboard
