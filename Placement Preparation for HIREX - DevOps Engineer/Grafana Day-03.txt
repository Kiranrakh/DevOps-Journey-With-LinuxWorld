🧱 STEP 1: INSTALL MYSQL ON EC2
==================================================================
# Repository + installation
sudo yum install https://dev.mysql.com/get/mysql80-community-release-el7-5.noarch.rpm -y
sudo yum install mysql-server -y
sudo systemctl start mysqld
sudo cat /var/log/mysqld.log
sudo mysql_secure_installation

🧠 Notes:
- This installs MySQL 8.x
- You’ll get a temporary password to change

🐍 STEP 8: CUSTOM METRICS WITH PYTHON
==================================================================

Diagram:

      [ Prometheus ] <--- Scrapes --- [ Python Exporter ]
                                         |
                                exposes metrics on :8080

Install:
pip3 install prometheus-client

mysqlapp.py:
```python
from prometheus_client import start_http_server, Summary
import time

REQUEST_TIME = Summary('req_process_sec', 'Time spent processing request')

@REQUEST_TIME.time()
def mysqlapp(t):
    time.sleep(t)

if __name__ == '__main__':
    start_http_server(8080)
    while True:
        mysqlapp(2)
````

Run:
python3 mysqlapp.py

\==================================================================
📡 STEP 9: ADD EXPORTER TO PROMETHEUS
=====================================

prometheus.yml:

```yaml
- job_name: 'mysql_python_exporter'
  static_configs:
    - targets: ['<EC2_IP>:8080']
```

Reload:
kill -HUP \$(pgrep prometheus)
