🔰 WHAT IS GIT?
--------------------------------------------------------------------
Git is a **Distributed Version Control System (DVCS)** that lets 
you track file changes, manage code collaboratively, and 
synchronize your work with others using remote repositories.

Created by: Linus Torvalds (2005)

Used in: GitHub, GitLab, Bitbucket, AWS CodeCommit, etc.

====================================================================
✅ KEY FEATURES OF GIT
====================================================================

1️⃣ **Distributed Architecture**
   - Every developer has a full local copy of the repository.
   - Work offline, sync later with remotes.

2️⃣ **Version Tracking**
   - Git stores every change to files, allowing you to:
     ✔️ Revert to previous states  
     ✔️ Compare versions  
     ✔️ Audit history

3️⃣ **Branching and Merging**
   - Create lightweight branches for features, bugs, or experiments.
   - Merge cleanly back to main.

4️⃣ **Fast and Lightweight**
   - Git operations (commit, diff, log) are fast and local.

5️⃣ **Staging Area (Index)**
   - Add files to a **staging area** before committing.
   - Gives control over what goes into a commit.

6️⃣ **Security and Integrity**
   - Git uses SHA-1 hashes to identify commits and protect data.
   - No corruption or tampering allowed.

7️⃣ **Collaboration**
   - Git supports multiple contributors via push/pull on shared remotes (like GitHub).
   - Perfect for DevOps teams and open-source work.

8️⃣ **Undo Mistakes**
   - With commands like `revert`, `reset`, `checkout`, Git allows recovery from most mistakes.

9️⃣ **Cross-platform**
   - Works on Linux, Windows, Mac, and integrates with IDEs and CI tools.

10️⃣ **Hooks and Automation**
   - Run scripts automatically on certain Git events (e.g., pre-commit, post-merge).

🌐 GITVIZ – VISUALIZE GIT OPERATIONS
====================================================================

🔹 GitViz is a **graphical tool** (or web-based simulator) that helps
you understand how Git works **visually**.

💡 Use it to:
✅ Simulate branching, merging, commits  
✅ See how HEAD, branches, and working directory relate  
✅ Understand rebases, fast-forwards, and detached HEADs
