==================================================================
📅 DAY 2: INTEGRATING PROMETHEUS WITH GRAFANA (Multi-EC2 Setup)
==================================================================

🎯 OBJECTIVE:
- Monitor multiple Amazon EC2 instances for system metrics and Docker container metrics
- Use Prometheus as a centralized monitoring system
- Visualize all data in Grafana using dashboards

==================================================================
🚀 STEP 1: LAUNCH EC2 INSTANCES (ON AWS)
==================================================================

🔹 Recommended EC2 Instances:
- EC2-1 → Prometheus Server
- EC2-2 → Docker Host + Node Exporter
- EC2-3 → Linux Host + Node Exporter
- EC2-4 → Grafana Server

✅ Common Setup for All:
- AMI: Amazon Linux 2
- Instance Type: t2.micro (Free tier eligible)
- Security Group: Allow TCP ports 22 (SSH), 9100, 9323, 9090, 3000
- Download Key Pair (.pem file) to access instances

AWS Launch Help:  
🔗 https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/EC2_GetStarted.html

==================================================================
📦 STEP 2: INSTALL NODE EXPORTER (on EC2-2 & EC2-3)
==================================================================

📘 Node Exporter collects system-level metrics like CPU, RAM, and network.

🔧 Commands:
```

sudo useradd --no-create-home --shell /bin/false node\_exporter
wget [https://github.com/prometheus/node\_exporter/releases/download/v1.8.0/node\_exporter-1.8.0.linux-amd64.tar.gz](https://github.com/prometheus/node_exporter/releases/download/v1.8.0/node_exporter-1.8.0.linux-amd64.tar.gz)
tar -xvzf node\_exporter-1.8.0.linux-amd64.tar.gz
sudo cp node\_exporter-1.8.0.linux-amd64/node\_exporter /usr/local/bin/
sudo chown node\_exporter\:node\_exporter /usr/local/bin/node\_exporter

```

📘 Setup systemd service:
```

sudo tee /etc/systemd/system/node\_exporter.service <\<EOF
\[Unit]
Description=Node Exporter
After=network.target
\[Service]
User=node\_exporter
ExecStart=/usr/local/bin/node\_exporter
\[Install]
WantedBy=default.target
EOF

sudo systemctl daemon-reexec
sudo systemctl enable node\_exporter
sudo systemctl start node\_exporter

```

Default Port: `9100`  
Docs: 🔗 https://prometheus.io/docs/guides/node-exporter/

==================================================================
🐳 STEP 3: ENABLE DOCKER METRICS (on EC2-2)
==================================================================

🔧 Commands:
```

sudo yum install docker -y
sudo systemctl enable docker
sudo systemctl start docker

sudo tee /etc/docker/daemon.json <\<EOF
{
"metrics-addr" : "0.0.0.0:9323",
"experimental" : true
}
EOF

sudo systemctl restart docker

docker run -d --name web nginx
docker run -d --name app httpd
docker stop web

```

Docker Metrics Port: `9323`

==================================================================
📡 STEP 4: INSTALL & CONFIGURE PROMETHEUS (on EC2-1)
==================================================================

```

wget [https://github.com/prometheus/prometheus/releases/download/v2.52.0/prometheus-2.52.0.linux-amd64.tar.gz](https://github.com/prometheus/prometheus/releases/download/v2.52.0/prometheus-2.52.0.linux-amd64.tar.gz)
tar -xvzf prometheus-2.52.0.linux-amd64.tar.gz
cd prometheus-2.52.0.linux-amd64
vim prometheus.yml

````

📘 Edit `prometheus.yml`:
```yaml
scrape_configs:
  - job_name: 'linux_node'
    static_configs:
      - targets: ['<EC2-3-IP>:9100']

  - job_name: 'docker_metrics'
    static_configs:
      - targets: ['<EC2-2-IP>:9323']

  - job_name: 'prometheus'
    static_configs:
      - targets: ['localhost:9090']
````

♻️ Reload Prometheus:

```
kill -HUP $(pgrep prometheus)
```

Port: `9090`
Docs: 🔗 [https://prometheus.io/docs/introduction/overview/](https://prometheus.io/docs/introduction/overview/)

\==================================================================
📊 STEP 5: INSTALL & CONFIGURE GRAFANA (on EC2-4)
=================================================

```
sudo tee /etc/yum.repos.d/grafana.repo <<EOF
[grafana]
name=Grafana OSS
baseurl=https://packages.grafana.com/oss/rpm
repo_gpgcheck=1
enabled=1
gpgcheck=1
gpgkey=https://packages.grafana.com/gpg.key
EOF

sudo yum install grafana -y
sudo systemctl enable grafana-server
sudo systemctl start grafana-server
```

Login:
URL → `http://<EC2-4-IP>:3000`
User → `admin` | Pass → `admin`
Docs: 🔗 [https://grafana.com/docs/](https://grafana.com/docs/)

\==================================================================
🧠 STEP 6: INTEGRATE PROMETHEUS INTO GRAFANA & CREATE DASHBOARDS
================================================================

➡️ In Grafana Web UI:

1. ⚙️ → Data Sources → Add Prometheus
2. Name: `Prometheus`
3. URL: `http://<Prometheus-EC2-IP>:9090`
4. Save & Test

➡️ Query & Visualize:

* Go to **Explore**
* Select metric: `node_cpu_seconds_total`, `container_memory_usage_bytes`, etc.
* Use `rate(...)` or `avg(...)` functions
* Add panel to dashboard

🧾 Save dashboard as **Multi-EC2 Monitoring**
